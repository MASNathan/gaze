# Repository guide

- `gaze.Outline` in `gaze.go` is the public library entrypoint; `php.go` extracts and formats PHP contracts. PHP is the only implemented language. CLI traversal and scan accounting live in `cmd/gaze`; library calls do not record stats.
- Compact output merges PHPDoc types into signatures without marking whether PHP enforces them. `--full` retains docblocks; `--no-docs` still uses PHPDoc for compact type inference. Preserve these distinctions when changing extraction.
- Go 1.27, CGO and a C compiler are required. Focused checks: `CGO_ENABLED=1 GOFLAGS=-mod=mod go test ./... -run TestName` or `CGO_ENABLED=1 GOFLAGS=-mod=mod go test ./internal/stats`. Set `CC` to an available compiler if needed. Stats tests isolate configuration via `XDG_CONFIG_HOME`.
- `make test` and `make build` use the existing vendor directory; `make install` first runs `make dep`. Current `make dep` only runs `go mod download` and `go mod vendor`: upstream Tree-sitter bindings reference C sources and headers that plain vendoring omits. If vendor-mode builds fail with missing `parser.c` or `tree_sitter/api.h`, use `GOFLAGS=-mod=mod` for checks; do not assume `make dep` repairs vendor despite README's claim. `make dep` replaces ignored `vendor/`.
- CLI scans persist aggregate-only SQLite metrics under `os.UserConfigDir()/gaze/stats.db`; output/token counters include directory headings, and a stats write failure makes the scan fail. `gaze stats` reads without recording a scan. Never store paths or source content in stats.
- Token counts use locally embedded `o200k_base` vocabulary; `internal/tokens.Count` rejects invalid UTF-8. Preserve token-counting semantics and private stats directory/database permissions.
- This is an independent MIT implementation inspired by zat: do not copy zat code, queries, fixtures, snapshots, or documentation.
